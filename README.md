## 📌 Ringkasan Proyek (Overview)

**CV Pelangi UV** adalah platform web modern kelas enterprise yang dirancang khusus untuk memenuhi kebutuhan industri pasca-cetak (*print finishing*) di Indonesia. Berbasis di kawasan industri **Bizpark Tambak Sawah Sidoarjo**, platform ini mengintegrasikan profil perusahaan, etalase layanan finishing presisi, grosir bahan baku berkualitas tinggi, galeri interaktif hasil cetak dengan zoom inspeksi, asisten konsultasi cerdas, serta **Admin CMS bawaan** untuk mengelola portofolio dan prospek (*leads*) secara terpusat.

Dibangun dengan arsitektur **Next.js 14 App Router**, TypeScript ketat (*strict type-safety*), dan Tailwind CSS teroptimasi, situs ini dirancang untuk kecepatan loading maksimal, SEO skor tinggi, serta responsivitas sempurna di seluruh perangkat desktop, tablet, dan smartphone.

## 🌟 Fitur Utama (Key Features)

### 1. 🎨 Showcase Jasa Finishing Lengkap
* **13+ Spesialisasi Cetak**: Spot UV Gloss & Pasir, Hot Stamping Foil (Gold, Silver, Hologram), Laminasi Thermal (Doff, Glossy, Soft Touch, Anti-Scratch), Pond Die-Cut, Emboss/Deboss, hingga Cast & Cure.
* Spesifikasi teknis terperinci mencakup ukuran kertas maksimal, ketebalan gramatur (*GSM*), kapasitas harian mesin, dan estimasi waktu pengerjaan.

### 2. 📦 Katalog Grosir Bahan Baku
* Distribusi langsung bahan pasca-cetak: **Roll Foil Stamping** (120m & jumbo roll), **Thermal BOPP Film**, **Lem Wet/Dry Laminating**, serta **Tinta & Varnish UV**.
* Layanan *custom slitting* (potong lebar roll presisi) sesuai spesifikasi mesin klien.

### 3. 🖼️ Galeri Pengaplikasian Produk Interaktif
* **Filter Multi-Kategori**: Pilah portofolio berdasarkan aplikasi (*Packaging Mewah, Label Stiker, Cover Buku, Hang Tag, Paper Bag*).
* **Modal Inspeksi Detail**: Zoom hasil cetak beresolusi tinggi, penjelas efek finishing yang digunakan, panduan pemilihan bahan, dan tombol pesan sampel fisik langsung.

### 4. 🛡️ Sistem Manajemen Admin (CMS Terintegrasi)
* **Dasbor Analitik**: Monitor jumlah portofolio aktif, total calon klien (*leads*), dan status pesanan sampel.
* **Manajer Galeri**: Tambah, edit, dan hapus foto/video portofolio secara dinamis dengan fitur upload media langsung.
* **Manajemen Leads & Inquiries**: Pantau permintaan penawaran harga dari form kontak, filter status (*Baru, Dihubungi, Sampel Terkirim, Selesai*), dan tombol direct chat WhatsApp ke klien.
* **Pengaturan Platform**: Kelola nomor WhatsApp hotline, jam kerja operasional pabrik, meta SEO, serta ganti kredensial password admin.

### 5. 🌐 Dukungan Multi-Bahasa & Navigasi Cerdas
* Fitur alih bahasa instan **Bahasa Indonesia (ID)** dan **English (GB)** yang halus dan terstruktur.
* Pencarian global cerdas (*modal search catalog*) untuk menemukan layanan dan bahan baku secara instan.

### 6. 🤖 Asisten Konsultasi & Direct CTA
* Chatbot interaktif ramah yang mampu memberikan saran teknis finishing cetak berdasarkan kebutuhan proyek klien.
* Tombol WhatsApp terintegrasi dengan template pesan otomatis untuk mempermudah alur komunikasi dengan tim marketing.

## 🚀 Cara Menjalankan (Getting Started)

### Prasyarat:
* **Node.js**: Versi `18.17.0` atau yang lebih baru
* **npm** atau **yarn**

### Langkah Instalasi:

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/Daffanugraha/Cv-Pelangi-Website.git
   cd Cv-Pelangi-Website
   ```

2. **Pasang seluruh dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan (Development Mode)**:
   ```bash
   npm run dev
   ```
   Buka peramban Anda di [http://localhost:3000](http://localhost:3000).

4. **Uji coba build produksi**:
   ```bash
   npm run build
   npm run start
   ```

## ☁️ Panduan Deploy ke Vercel (1-Click Deploy)

Website ini 100% kompatibel dan dioptimasi secara khusus untuk deployment di **Vercel**:

1. Buka [Vercel Dashboard](https://vercel.com/dashboard) dan masuk dengan akun GitHub Anda.
2. Klik tombol **"Add New..."** lalu pilih **"Project"**.
3. Cari dan pilih repository **`Daffanugraha/Cv-Pelangi-Website`**, lalu klik **"Import"**.
4. Biarkan konfigurasi build bawaan (*Framework Preset: Next.js*).
5. Klik **"Deploy"**. Dalam hitungan 1-2 menit, situs Anda sudah live di internet dengan domain aman SSL gratis!
