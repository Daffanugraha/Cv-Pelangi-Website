## 📌 Ringkasan Proyek (Overview)

**CV Pelangi UV** adalah platform web korporat dan katalog digital modern yang dirancang khusus untuk memenuhi kebutuhan industri pasca-cetak (*print finishing*) di Indonesia. Berbasis di kawasan industri **Bizpark Tambak Sawah Sidoarjo**, platform ini mengintegrasikan profil perusahaan, etalase layanan finishing presisi tinggi, distribusi grosir bahan baku, galeri pengaplikasian produk cetak interaktif, blog edukasi industri percetakan, asisten AI chatbot teknis berbasis backend aman, serta **Admin CMS bawaan** untuk manajemen portofolio dan prospek (*leads*).

Dibangun dengan arsitektur **Next.js 14 App Router**, TypeScript ketat (*strict type-safety*), dan Tailwind CSS teroptimasi, platform ini dirancang untuk performa loading secepat kilat, SEO skor tinggi, serta pengalaman pengguna yang mulus di seluruh perangkat desktop, tablet, dan smartphone.

## 🌟 Fitur Utama (Key Features)

### 1. 🎨 Portofolio Layanan Finishing Cetak
* **13+ Solusi Finishing Presisi**: Spot UV Gloss & Pasir Taktil, Hot Stamping Foil (Gold, Silver, Rose Gold, Hologram), Laminasi Thermal BOPP (Doff Halus, Glossy Bening, Velvet Soft-Touch, Anti-Scratch), Pond & Die-Cutting Otomatis, Deboss/Emboss, Window Lamination, hingga Cast & Cure efek prisma mikro.
* Informasi spesifikasi teknis lengkap mencakup gramatur kertas (*GSM*), ukuran plano maksimal, kapasitas mesin harian (200.000+ lembar/hari), serta estimasi lead time.

### 2. 📦 Katalog Grosir Bahan Baku Pasca-Cetak
* Pasokan bahan baku industri berkualitas tinggi: **Roll Foil Hot Stamping** (panjang 120m & jumbo roll hingga 3.000m), **Thermal BOPP Film**, **Lem Waterbase & Hotmelt**, serta **Varnish & Tinta UV**.
* Layanan *custom slitting* (potong lebar roll dengan toleransi ±0.5 mm) sesuai spesifikasi mesin cetak mitra.

### 3. 🖼️ Galeri Pengaplikasian Produk Interaktif
* **Koleksi Portofolio Nyata**: 18+ variasi produk kemasan nyata mencakup *Kemasan Rokok & Sigaret, Dus Box Skincare & Parfum Luxury, Box Makanan Food-Grade, Hardcover Agenda & Buku Tahunan, Kartu Nama Cotton & Identity, serta Paper Bag Butik*.
* **Sistem Pagination Dinamis (`1 2 3 ... N`)**: Navigasi halaman bernomor responsif dengan elipsis otomatis dan auto-scroll yang nyaman.
* **Tampilan Kartu Bersih & Elegan**: Visual kartu produk modern dan rapi tanpa badge kaku yang mengganggu.
* **Modal Inspeksi Detail**: Popup modal spesifikasi teknis bahan, teknik finishing terapan, dan tombol pemesanan sampel fisik langsung.

### 4. 📰 Blog & Wawasan Industri Percetakan
* Pusat artikel edukasi dan panduan teknis pasca-cetak (standar cetak kemasan rokok, sertifikasi food-grade, tren foil hologram, tips pencegahan kerut laminasi, dll.).
* Dilengkapi filter kategori, kolom pencarian cerdas, dan navigasi pagination dinamis berhalaman jamak.

### 5. 🤖 Pelangi AI Assistant (Konsultan Teknis Cerdas)
* Chatbot interaktif cerdas yang ditenagai backend API terisolasi aman (kunci API aman di sisi server, bebas kebocoran kredensial di frontend).
* **Multi-Turn Context Awareness**: AI mengingat histori percakapan pengguna, memahami konteks pertanyaan lanjutan, dan mengenali sapaan personal.
* **Rekomendasi Terstruktur & Tepat Sasaran**: Menjawab kebutuhan finishing (seperti kemasan rokok, skincare, dll.) secara padat dan akurat sesuai data resmi website, lengkap dengan tautan langsung (*direct WhatsApp*) ke 3 tim marketing representatif: Ibu Dewi, Bpk. Hendra, dan Bpk. Bambang.

### 6. 🛡️ Sistem Manajemen Admin (CMS Terintegrasi)
* **Dasbor Analitik**: Monitor jumlah item galeri aktif, calon mitra (*leads*), dan permintaan sampel fisik.
* **Manajer Portofolio**: Kelola data visual produk galeri secara dinamis dengan unggah media langsung.
* **Manajemen Prospek & Pesanan Sampel**: Pantau formulir penawaran harga dari calon mitra dengan status terstruktur (*Baru, Dihubungi, Sampel Terkirim, Selesai*).
* **Pengaturan Platform**: Kelola nomor WhatsApp hotline, alamat pabrik, jam operasional, dan kredensial akses admin.

## 🚀 Cara Menjalankan (Getting Started)

### Prasyarat:
* **Node.js**: Versi `18.17.0` atau yang lebih baru
* **npm** atau **yarn**

### Langkah Instalasi:

1. **Clone repository**:
   ```bash
   git clone https://github.com/Daffanugraha/Cv-Pelangi-Website.git
   cd Cv-Pelangi-Website
   ```

2. **Pasang seluruh dependensi**:
   ```bash
   npm install
   ```

3. **Konfigurasi Environment Variables**:
   Buat file `.env.local` di root folder proyek:
   ```env
   # API Key untuk Asisten AI (Server-Side Only)
   GEMINI_API_KEY=your_gemini_api_key_here

   # Kredensial Login Admin Panel
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=your_secure_password
   ```

4. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```
   Buka peramban di [http://localhost:3000](http://localhost:3000).

5. **Uji coba build produksi**:
   ```bash
   npm run build
   npm run start
   ```

## ☁️ Panduan Deploy ke Vercel (1-Click Deploy)

Platform ini siap dideploy langsung ke **Vercel**:

1. Masuk ke [Vercel Dashboard](https://vercel.com/dashboard) dengan akun GitHub Anda.
2. Klik tombol **"Add New..."** &gt; **"Project"**.
3. Pilih repository **`Daffanugraha/Cv-Pelangi-Website`**, lalu klik **"Import"**.
4. Di bagian **Environment Variables**, masukkan variabel yang dibutuhkan (misal: `GEMINI_API_KEY` dan `ADMIN_PASSWORD`).
5. Klik **"Deploy"**. Website akan selesai dibangun dan langsung live dengan SSL otomatis!
